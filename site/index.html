Workbench

A keyboard-driven terminal workbench for local files.

Convert, compress, transcribe, and transform. Batch it, chain it, or hand it to an agent.

Quickstart

01brew install solomonadzape95/tap/workbench
02wbopen the TUI
03wb run --op image.convert --input "*.png"

Build a chain once, save it with ctrl+s, and re-run it with ctrl+r.

What it does

imageconvert · resize · crop · remove bg · upscale
audionormalize · transcribe · vocals · instrumental
videotrim · compress · concat · transcribe
documentOCR · split · translate · summarize
filearchive · extract · hash · dedupe

65 operations · five domains · one binary.

Three ways in

Run it your way.

In the TUI

Pick an operation, set a few fields, and watch the job list. The whole workbench lives in one terminal screen.

wb

From a command

Run one operation or a saved pipeline. Globs, filters, and dry runs are built in for shell work.

wb run --op image.convert --input "*.png"

From an agent

Expose the same runner over HTTP or MCP. Start jobs, stream events, and download outputs.

wb serve  ·  wb mcp

Local by default

Your files stay yours.

Workbench runs on your machine and delegates to tools you control. There is no upload step and no account. Install only the engines you need; missing ones never block unrelated work.
