Quickstart

Install, launch, and run your first job.

01
Install with Homebrew
$brew install solomonadzape95/tap/workbench
02
Launch the TUI
$wb
03
Run an operation
$wb run --op image.convert --input "*.png"
04
Check your engines
$wb doctor

tip Save a chain with ctrl+s, replay it with ctrl+r.
